# 墨账 Ink Ledger · finance-app 界面设计方案 — 总览

## 交付物
- `design/ui-redesign-proposal.html` — 完整设计方案（设计原则、Token 系统、组件规范、两大核心界面高保真模型、动效/无障碍/实施映射），右上角开关可实时切换明暗双主题预览
- `.impeccable.md` — 项目设计上下文（风格方向、用户场景、语义色约定），供后续设计工作复用

## 设计主张：把数字记进一本值得信任的账
- **风格**：精致账本质感 — 暖纸底色 + 墨蓝黑文字 + 靛青主色 + 朱砂印章点缀；衬线标题、等宽右对齐数字、发丝线分隔的账本式列表、合计双下划线
- **四条设计原则**：数字是第一公民 / 一条线胜过一张卡 / 朱砂惜墨如金 / 键盘与右手优先
- **双主题**：亮色「纸」(#F7F5F0) 与暗色「墨夜」(#10141F) 各自成体系，token 一一对应

## 关键设计决策
1. **双语义色约定**：流水沿用「收入青竹绿 / 支出赭红」（产品既有约定）；资产行情遵循中国用户习惯「红涨绿跌」，并始终配 ▲▼ 符号
2. **账本行替代卡片套卡片**：明细/账户列表用 hairline 行，信息密度 +40%，扫读更快
3. **朱砂红仅限三处**：Logo 印章、危险操作、上涨标记
4. **零网络字体依赖**：衬线走 Noto Serif SC/宋体系系统栈，数字用 tabular-nums
5. **改造路径最低成本**：全部 token 映射到现有 `src/index.css` CSS 变量体系，组件 API 不动

## 无障碍
- 正文对比度 ≈ 14:1（亮）/ 12:1（暗），语义色 ≥ 4.5:1，WCAG AA
- 涨跌不依赖颜色（▲▼ + 文字）；键盘完整可用；触控目标 ≥ 44px；尊重 prefers-reduced-motion
