DESIGN PROPOSAL · 个人记账与资产工作台

把数字，记进一本值得信任的账。

「墨账」以私人账本为隐喻：暖纸底色与靛青墨色构成安静的书页，衬线标题与等宽数字赋予账目以仪式感，朱砂印章只在该出现的地方出现。信息密度服务于桌面端高效复盘，明暗双主题各成一体。

精致账本质感 桌面优先 明暗双主题 WCAG AA Tailwind / shadcn 兼容
壹设计原则

四条原则约束所有界面决策，任何新组件先对照这四条再动手。

原则 01

数字是第一公民

金额一律等宽数字（tabular-nums）右对齐；层级靠字重与字号区分而非颜色堆叠；合计使用账本式双下划线，读数零歧义。

本月合计 ¥6,842.50
原则 02

一条线，胜过一张卡

账目列表用发丝线（hairline）分隔而非卡片套卡片——密度更高、扫读更快，也更像账本。卡片只用于真正独立的信息块（总览、图表、表单）。

原则 03

朱砂惜墨如金

印章红是品牌记忆点，但只用在三处：Logo 印章、破坏性/警示操作、以及行情上涨。满页皆红，红就失去了意义。

墨 ▲ +2.4%
原则 04

键盘与右手优先

桌面端高频动作（记一笔、批量录入）永远在右上角拇指热区；Enter 提交、Esc 关闭、Tab 顺序即视觉顺序；焦点环 2px 靛青 + 2px 偏移，可见但不刺眼。

贰设计基石 · 色彩

配色延续产品既有 token 结构（HSL CSS 变量 → Tailwind），只精修数值。切换右上角主题开关可同时预览两套色板的实际观感。

双语义色约定（重要）：流水场景（记一笔、明细列表）沿用产品既有「收入=青竹绿、支出=赭红」；资产行情场景（总资产环比、余额月报环比）遵循中国用户习惯「红涨 绿跌」。两套规则在图例处始终显式标注，不靠猜。

字体排版 · Typography

展示层用衬线（Noto Serif SC / 宋体系）营造账本质感；正文用系统无衬线保证可读性；所有数字启用等宽数字特性。零网络字体依赖，本地应用即刻可用。

陆交互与动效

动效只服务状态变化，绝不动画化布局属性；全部缓动使用 ease-out-quart 家族，尊重系统「减少动态效果」偏好。

场景规格时长 / 缓动
按钮 / 行悬停背景色过渡 + 主按钮上浮 1px + 阴影加深150ms · ease-out
输入聚焦边框变靛青 + 3px 光环（--focus-ring），光环从不裁切150ms · ease-out
弹窗（记一笔 / 批量录入）遮罩淡入 + 面板 12px 上浮 + 缩放 98%→100%；Esc 关闭、Enter 提交300ms · ease-out-quart
小项目展开/折叠高度过渡 + 子行依次 40ms 阶梯淡入（stagger）240ms · ease-out
数字卡更新金额数字滚动计数（仅英雄总资产与大数字卡）500ms · ease-out
Toast 反馈右侧滑入，2.4s 自动退出，连续操作仅保留最新一条240ms · ease-out
主题切换背景/文字颜色整体过渡（color-mix 兼容降级为瞬时切换）300ms · ease-out
柒无障碍与响应式

全部交互目标满足 WCAG 2.1 AA；桌面优先但完整定义降级路径。

项目标准与做法
正文对比度墨 #1C2333 / 纸 #F7F5F0 ≈ 14:1；暗色米白 #E9E6DD / 深墨 #10141F ≈ 12:1，远超 AA（4.5:1）
语义色对比度青竹 #1F7A57、赭红 #D9472F、靛青 #3E5FA8 在纸底上均 ≥ 4.5:1（小字号加粗使用）
涨跌不依赖颜色▲▼ 符号 + 百分比文字与颜色同现，色弱可辨
键盘Tab 顺序 = 视觉顺序；焦点环 2px 靛青偏移 2px 永不隐藏；N 键快捷呼出「记一笔」
触控目标所有可点击行高 ≥ 44px（含移动端降级）
屏幕阅读器金额 aria-label 读作「支出 三十二元」；图表提供表格摘要（Recharts 已有 tabular 数据）
减少动态prefers-reduced-motion 时关闭计数动画与阶梯淡入
断点≥1280px 三栏满血 · 1024–1279 两栏 · 768–1023 单栏+顶部标签 · <768 侧栏收为底部导航，记一笔变为底部常驻按钮（保底可用，不隐藏关键功能）
打印保留现有 A4 打印样式；新账本行在打印态去阴影、黑色单色、合计保留双下划线
捌实施映射

设计 token 与现有 src/index.css 的 CSS 变量体系一一对应，改造集中在「换值 + 少量新增」，不动组件 API。

设计 Token落点说明
--paper / --paper-2 / --paper-3--background / --card / muted替换现有 HSL 值为暖纸/深墨体系
--ink / --ink-2 / --ink-3--foreground / --muted-foreground墨色阶，暗色反转
--indigo--primary / --ring靛青精修：HSL(226 46% 45%)
--seal新增变量朱砂印章色，用于 Logo、危险操作、涨
--income / --expense沿用现有变量名数值微调至 AA 对比度
--up / --down新增变量行情语义「红涨绿跌」，组件内统一用 ▲▼
衬线标题 / 等宽数字index.css 字体栈 + .num { font-variant-numeric: tabular-nums }零网络字体，系统字体栈
账本行 Ledger RowRecordList / AssetTable 重构为 hairline 行替换卡片式列表，密度 +40%
合计双下划线工具类 .rule-double { border-bottom: 3px double }总资产卡、报表合计、明细合计三处使用
噪点纸纹保留现有 body 噪点，透明度降至 0.018暗色主题保留径向光斑
落地顺序建议：① 先换 token 值（半天，全站即刻换装）→ ② 账本行重构 RecordList / AssetTable → ③ 总资产英雄卡 + 环比红涨绿跌 → ④ 记一笔弹窗交互打磨（Enter 链、Toast）。每步独立可验收，随时可回滚。
